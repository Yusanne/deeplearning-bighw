# Evidence Diagnostic 证据干预查看台

## 推荐方式：直接发 Excel

这是一个用于查看证据干预条件的离线前端。主实验不要求完成 20 题人工标注；已有 Excel/JSON 只作为 pilot 素材和可选案例抽查。

```text
CiteFaith_Pilot20_简易标注表.xlsx
```

简易版只需要看三个工作表：

- `开始这里`：用最直白的步骤说明怎么填；
- `请填写`：一题一行，只有黄色列需要填写；
- `看证据`：按题号筛选原始、替换、良性和删除世界的证据全文。

简易版需要填写的核心内容只有：替换结果、替换后的答案、正证据是否支持、良性页是否合格、事实出现次数和备注。主表**不包含模型输出**，是为了避免模型答案影响人工判断。

“看证据”表最后增加了中文辅助翻译列，使用 Excel 365 的 `TRANSLATE` 函数自动生成。英文原文仍然保留，数字、日期和专有名词必须以英文原文核对；如果使用的 Excel/WPS 不支持该函数，中文列可能为空，此时可使用软件自带翻译功能。

短复核表生成后再按正式分工复制给双方。推荐文件名：

```text
CiteFaith_Pilot20_标注_张轩晨.xlsx（8 个独立题 + 5 个共同题）
CiteFaith_Pilot20_标注_潘雨萱.xlsx（7 个独立题 + 5 个共同题）
```

收到两份简易版文件后，可以自动合并并标出分歧：

```bash
python3 app/merge_simple_annotation_xlsx.py \
  CiteFaith_Pilot20_标注_张轩晨.xlsx \
  CiteFaith_Pilot20_标注_潘雨萱.xlsx \
  --out CiteFaith_Pilot20_简易合并复核.xlsx
```

合并文件包含 `合并复核` 和 `一致性统计` 两个工作表，自动计算原始一致率、Cohen's κ，并用红色标出需要讨论的题目。

旧版的完整模板 `CiteFaith_Pilot20_标注模板.xlsx` 仍保留，但不建议直接发给不熟悉项目的人。

这是一个无需后端、无需安装依赖的离线前端，用于查看 `week1/results/worlds/` 中的四种证据条件。页面使用“原始证据条件、证据删除条件、证据替换条件、无关证据添加条件”的术语；人工抽查最多 5 个案例，不是主实验前置条件。

## 使用方法

推荐在项目根目录运行：

```bash
python3 -m http.server 8000
```

然后打开：

```text
http://localhost:8000/app/
```

点击“加载 worlds 文件夹”，选择：

```text
week1/results/worlds/
```

如果需要同时查看模型输出，再点击“可选：加载模型输出”，选择：

```text
week1/results/llm/
```

浏览器会将标注自动保存到 `localStorage`。完成后点击“导出当前标注”或“导出全部标注”。

## 可选案例抽查

1. 从自动结果中挑选不超过 5 个代表性案例；
2. 可使用不同浏览器或清空本地缓存，保持判断独立；
3. 导出 JSON 后作为答辩案例或定性误差分析素材，不计算大规模一致率。

## 标注原则

- `flip`：替换页支持一个与原答案不同、且可以明确判定的新答案；
- `unanswerable`：替换页不能支持新答案，模型应拒答；
- `invalid`：替换页主题不符、没有改变事实、文本不自然或无法可靠判断；
- “规则代理”只作程序提示；自动结果是主分析，人工抽查只用于解释案例；
- 扫描件、答案格式不一致、图表依赖分别使用对应的文本问题标签，不要直接记成 swap 失败。
